# MeshChat LoRa রিলে নোড (ESP32 + RA-02)

ফোন ↔ **BLE** ↔ রিলে ↔ **LoRa** ↔ রিলে ↔ **BLE** ↔ ফোন।
সাথে নিজস্ব চ্যাট: **কিবোর্ড + 1602 LCD** এবং **Wi-Fi হটস্পটে ওয়েব চ্যাট + সেটআপ পেজ**।

হার্ডওয়্যার: ESP32 DevKit V1 · LoRa RA-02 (SX1278) · LCD 1602 · কিবোর্ড (নিচে USB নিয়ে নোট দেখুন)।
ফোনের অ্যাপে কোনো পরিবর্তন লাগে না।

> 📌 **সততার সাথে অবস্থা:** মেশের কোর লজিক (প্যাকেট, এনক্রিপশন, LoRa ফ্র্যাগমেন্ট, রাউটিং, ফ্লাডিং, রিট্রাই, কিবোর্ড ডিকোডার, আবহাওয়া) পিসিতে পরীক্ষিত (১৪৮টি চেক) এবং অ্যাপের **আসল Kotlin কোড** দিয়ে বানানো প্যাকেটের সাথে দুই দিকে মেলানো হয়েছে। কিন্তু **BLE, LoRa রেডিও, LCD, Wi-Fi/ওয়েব সার্ভারের বোর্ড-কোড (`src/`)** এই পরিবেশে কম্পাইল বা বোর্ডে চালানো যায়নি। প্রথম কম্পাইলে ছোটখাটো লাইব্রেরি-সংস্করণের ত্রুটি আসতে পারে — আসলে এরর লগ পাঠালে ঠিক করে দেব।

## ১. কী কী লাগবে
| জিনিস | মন্তব্য |
|---|---|
| ESP32 DevKit V1 | |
| LoRa RA-02 (SX1278, 433 MHz) + ব্রেকআউট বোর্ড + অ্যান্টেনা | **অ্যান্টেনা ছাড়া চালাবেন না** |
| LCD 1602 (I2C ব্যাকপ্যাকসহ হলে ভালো) | |
| কিবোর্ড | **ESP32 DevKit V1-এ USB host নেই** — PS/2 কিবোর্ড, বা সিরিয়াল টার্মিনাল (`docs/WIRING.md` দেখুন) |
| 100 µF ক্যাপাসিটর, 1 kΩ ও 2 kΩ রোধ ×২ সেট (PS/2-র জন্য) | |

ওয়্যারিং: **`docs/WIRING.md`** (ছবি: `docs/wiring_diagram.png`, BMP280 সহ হালনাগাদ)। অ্যাপের স্ক্রিন-নকশা: **`docs/app_screens/`**।

## ২. বিল্ড ও ফ্ল্যাশ
1. VS Code + **PlatformIO** ইনস্টল করুন (বা `pip install platformio`)।
2. এই ফোল্ডার খুলুন, বোর্ড USB-তে লাগান।
3. `pio run -t upload` তারপর `pio device monitor` (115200)।
   প্রথম বুটে সিরিয়ালে দেখাবে: `node id MC-F3…`, `lora: 433.000 MHz … ready`, `wifi: AP 'MeshChat-Relay'`।
4. LCD ব্যাকপ্যাক ছাড়া হলে `platformio.ini`-তে `-DLCD_I2C=0`।

## ৩. প্রথম ব্যবহার
1. ফোন/ল্যাপটপে Wi-Fi **`MeshChat-Relay`**, পাসওয়ার্ড **`meshchat123`** → চ্যাট পেজ নিজে খুলবে (না খুললে `http://192.168.4.1`)।
2. **`http://192.168.4.1/setup`** — ইউজার `admin`, পাসওয়ার্ড `admin1234`।
   🔴 **প্রথমেই Wi-Fi পাসওয়ার্ড ও সেটআপ পাসওয়ার্ড বদলান।**
3. Setup পেজে: ডিভাইসের নাম, Wi-Fi, LoRa (ফ্রিকোয়েন্সি, SF, ব্যান্ডউইথ, পাওয়ার, sync word, ডিউটি সাইকেল), LCD ঠিকানা, নতুন Node ID, ফ্যাক্টরি রিসেট। সেভ করলে বোর্ড রিবুট হয়।
4. **দুই (বা বেশি) রিলেতে LoRa সেটিং হুবহু এক হতে হবে** (ফ্রিকোয়েন্সি, SF, BW, CR, sync word)।
5. MeshChat অ্যাপ খুলে রাখুন: ফোন রিলেকে নিজে খুঁজে সংযুক্ত হবে (সাধারণত ১০–৩০ সেকেন্ড)। এরপর অ্যাপে রিলের নাম একজন "নোড" হিসেবে দেখা যাবে, আর LoRa-র ওপারের মানুষরাও পরিচয় বিনিময়ের পর (কয়েক মিনিটের মধ্যে) তালিকায় আসবে।

## ৪. চ্যাট করার উপায়
- **ওয়েব (Wi-Fi):** উপরে নাম লিখুন, "সবার জন্য" বা একজনকে বেছে নিন, লিখে পাঠান। বাংলা চলবে।
- **কিবোর্ড + LCD:** টাইপ → `Tab` দিয়ে কাকে পাঠাবেন → `Enter`। LCD-তে ইংরেজি/ASCII ছাড়া অক্ষর `?` দেখাবে। নতুন মেসেজ এলে LCD-তে ঘুরে ঘুরে দেখায়, SOS এলে `!!! S O S !!!` ঝলকায়।
- **ফোনের অ্যাপ:** আগের মতোই।

## নতুন (ফার্মওয়্যার ১.৪ + অ্যাপ): 🌤 আবহাওয়া স্টেশন

প্রতিটি রিলে নোডে **BMP280** (বা BME280) লাগালে নোডের **পরিচয়ের (IDENTITY) সাথে একটি বাড়তি ঘর** যোগ হয়: **তাপমাত্রা (°C)** ও **বায়ুচাপ (hPa)**। নাম, Node ID ও চাবির পাশাপাশি এটাও সাইন হয়ে যায়, আর **ডিভাইস লিস্টে নামের পাশেই দেখায়**। আলাদা চ্যাট পোস্ট যায় না, পাবলিক বোর্ডে কিছু জমে না।

- **ওয়্যারিং:** `docs/WIRING.md` §৭ (LCD-র SDA/SCL-এ সমান্তরালে, GPIO 21/22)।
- **সময় নিজে ঠিক করুন:** `http://192.168.4.1/setup` → **"আবহাওয়া স্টেশন"** কার্ড: চালু/বন্ধ, **১–১৪৪০ মিনিট** (ডিফল্ট ৫)। রিবুট লাগে না। **"এখনই পাঠান"** বোতামও আছে। ব্যবধানের সাথে ০–১০% এলোমেলো যোগ হয়, যাতে একসাথে চালু হওয়া নোড একসাথে না বলে।
- **কোথায় দেখাবে:** (১) **MeshChat অ্যাপের Nearby (ডিভাইস) তালিকায় নামের নিচে** `🌡 27.5 °C · 1008.2 hPa · ৩ মি আগে`; (২) ওয়েব পেজে স্টেশন-কার্ড ও পাঠানোর তালিকায় নামের পাশে; (৩) LCD-তে স্টেশন একটা একটা করে (`F1`-এ হাতে বদল)।
- **এয়ারটাইম:** আবহাওয়াসহ পরিচয় শুধু আপনার ঠিক করা ব্যবধানে যায় (সাধারণ ১২ মিনিটের পরিচয় বীকনে আবহাওয়া থাকে না)। LoRa হপ সীমা পরিচয়ের মতোই। অনেক নোড থাকলে ব্যবধান বাড়ান।
- **সেন্সর না থাকলে** নোড আগের মতো চলে, আবহাওয়া পাঠায় না (প্রতি মিনিটে সেন্সর খোঁজে)।
- ⚠️ **পুরোনো অ্যাপ (২.১১) ও আবহাওয়াসহ পরিচয়:** আবহাওয়াসহ পরিচয়ের বাইট-ফরম্যাট পুরোনো অ্যাপ চেনে না (ই-মেইলের মতোই), সে ঐ পরিচয় বাদ দেবে। তাই **এই ফার্মওয়্যারের সাথে অ্যাপটিও নতুন সংস্করণ চালাতে হবে** (দুটো একসাথে)। আবহাওয়া ছাড়া পরিচয়ের বাইট আগের মতোই।
- 🔌 বোর্ড-কোড (`bmp280.cpp`, `weather.cpp`, ওয়েব/LCD) ও অ্যাপের Kotlin কোড আমি এই পরিবেশে কম্পাইল/চালাইনি। হিসাব, ফরম্যাট ও দুই-রিলে LoRa চেইন পিসিতে পরীক্ষিত।

## ফার্মওয়্যার ১.২ (অ্যাপ ২.১১-এর সাথে)

- **নিজের পরিচয় দেয়:** BLE বিজ্ঞাপন, HELLO ও IDENTITY-তে `LORA` ক্যাপ বিট (৮)। অ্যাপ রিলেকে এভাবে চেনে।
- **পরিচয় অনুরোধ (IDENTITY_REQ, টাইপ ১২):** ফোন কারো চাবি চাইলে রিলে নিজের মেমরি থেকে সাথে সাথে উত্তর দেয়, রেডিওতে কিছু যায় না। অচেনা হলে অনুরোধ LoRa পার হয়ে যায়।
- **ফ্লাড কমানো:** ফোনের বারবার পাঠানো পরিচয় আর LoRa-তে যায় না। নতুন পরিচয় একবার যায়, তারপর বীকন সময়সূচি (ডিফল্ট ১২ মিনিট; চ্যানেল ব্যস্ত হলে ৪ গুণ পর্যন্ত ধীর)।
- **LoRa-তে হপ সীমা:** পাবলিক পোস্ট ও পরিচয় সর্বোচ্চ ৬ হপ (সেটআপ পেজে ২–১৬ বদলানো যায়)। SOS ও ব্যক্তিগত মেসেজের সীমা কমে না।
- **শোনার পর বলা (listen before talk):** ট্রান্সমিটের আগে চ্যানেল ব্যস্ত কি না দেখে (ব্যস্ত হলে একটু অপেক্ষা, সর্বোচ্চ ৮ বার, তারপর পাঠায়)।
- **LoRa-পথ চিহ্ন:** HELLO-তে প্রতিটি দূরের নোডের পাশে চিহ্ন থাকে (হপ বাইটের উপরের বিট)। অ্যাপ এটা দেখে ঐ নোডের জন্য ভয়েস/PTT/ছবি/ফাইল/কল বন্ধ করে। একই রিলের ফোনে চিহ্ন থাকে না।
- **LED ও স্পিকার:** নতুন মেসেজ/SOS-এ আলো ও টোন (GPIO 2 ও 17, `docs/WIRING.md` §৬)। সেটআপ পেজে চালু/বন্ধ, শুধু-আলো মোড, পিন বদল।
- সেটআপ পেজে নতুন ঘর: "Max LoRa hops".

## ৬. সমস্যা হলে
| লক্ষণ | করণীয় |
|---|---|
| সিরিয়ালে `lora: begin failed (-2)` | RA-02 ওয়্যারিং, 3.3 V, NSS/RST পিন, অ্যান্টেনা দেখুন |
| LCD-তে আলো আছে, লেখা নেই | কনট্রাস্ট ট্রিমার ঘোরান; I2C ঠিকানা (27/3F) Setup-এ বদলান |
| ফোন রিলেকে পাচ্ছে না | অ্যাপের ব্লুটুথ/লোকেশন পারমিশন, ফোনের ব্লুটুথ চালু? রিলের পাওয়ার ভালো? |
| ওপারের মানুষ তালিকায় আসছে না | LoRa সেটিং মেলান; ১২ মিনিট পর্যন্ত অপেক্ষা (বীকন); `LoRa rx/tx` সংখ্যা Setup-এ দেখুন |
| মেসেজ ধীরে যাচ্ছে | SF কমান (7–9) বা ডিউটি সাইকেল বাড়ান (আপনার দেশের নিয়ম মেনে) |
| Wi-Fi ও BLE একসাথে ধীর | ESP32-র একটাই রেডিও; ঘটনাটা স্বাভাবিক, ফোনের সংখ্যা কম রাখুন |

## ৭. আইনি/নিরাপত্তা
- ফ্রিকোয়েন্সি, ট্রান্সমিট পাওয়ার ও ডিউটি সাইকেল **আপনার দেশের নিয়ম** অনুযায়ী ঠিক করুন (বাংলাদেশে 433 MHz ব্যবহারের নিয়ম আমি যাচাই করিনি — BTRC-র সাথে দেখে নিন)।
- ডিফল্ট পাসওয়ার্ড বদলান। রিলে একটি শেয়ারড টার্মিনাল (`docs/HOW_IT_WORKS.md`)।
- ফোন-ফোন প্রাইভেট চ্যাট এন্ড-টু-এন্ড এনক্রিপ্টেড; রিলে মাঝখানে শুধু সাইফারটেক্সট দেখে।

আরও: **`docs/HOW_IT_WORKS.md`** (প্রোটোকল ও সীমাবদ্ধতা)।

## ⌨ ব্লুটুথ কীবোর্ড (১.৫)
- রিলে **BLE** কীবোর্ড (HID over GATT) জোড়া যায়; লেখা PS/2 কীবোর্ডের মতোই চ্যাটে যায়। সাধারণ ক্লাসিক-ব্লুটুথ কীবোর্ড চলবে না, শুধু BLE।
- জোড়া লাগানো: সেটআপ পেজ → "ব্লুটুথ কীবোর্ড" → 🔍 খুঁজুন (কীবোর্ডকে আগে পেয়ারিং মোডে দিন) → Pair। LCD/ওয়েবে ৬ অঙ্কের কোড আসে, সেটি কীবোর্ডে টাইপ করে Enter দিন (কিছু কীবোর্ড কোড চায় না)।
- একবার জোড়া হলে কীবোর্ড জাগলেই আপনা-আপনি যুক্ত হয়; ৪টি ফোনের সংযোগে বাধা দেয় না। কোনো নতুন তার লাগে না।
